## 2. Decompose reference drift with saved tasks

Hypotheses distinguished: replay-distribution change; normalization change; teacher/target realization; learner parameter change; architecture-dependent optimizer sensitivity. Focus on humanoid-run where large negative deficits mostly follow fresh decline, with dog-run as a contrasting trained-specific deterioration control.

Design: select small/large critics, training seeds2–5 (four per cell, excluding hypothesis-generating seed1), early and70% checkpoints. For the same saved fresh initialization cross replay support(early/late) × observation normalization(early/late) × teacher realization(early/late), while retaining identical minibatch indices and original own-offset semantics in the primary diagnostic. Include trained copies on the same materialized task. Keep actual target arrays, pool identifiers and offsets; do not conflate own-offset versus shared-target variants. Freeze choices with the researcher before fitting.

Measurements: pre-update full-pool and fixed-batch error; intermediate fixed-pool MSE; changing-minibatch MSE; final pool and held-out error; centered output variance, output/base covariance, target variance; first-update parameter and prediction displacement; gradient/update norms and exact optimizer state. Primary contrasts: within-parent task-component changes, summarized first per training seed then across seeds. Use paired seed bootstrap; do not count eight task variants as eight training seeds.

Prefer recovering equivalent stored fits, which costs no new optimization.

Predictions: replay/normalization cause should change fresh performance when only those components change. A pure learner-history mechanism should survive fixed task components. A teacher realization effect should vary strongly with target swaps, reducing a deterministic “training-time” story. Failure: no component-specific reproducible contrast beyond seed/task noise. ## 3. Distinguish optimizer overshoot and fitting-budget limitations

Select original dog medium/large tasks showing verified spikes after archive recovery, plus pen small seed5 and independent seeds2–5. Do not select only high-amplification examples; include all selected seed/task cells and a no-spike control. Compare original learning rate to0.5× and0.25× at fixed AdamW decay, initialization, task and minibatch stream. Compare continuous horizons2000/4000/8000 with preserved prefixes and carried optimizer state. These are explicitly new mechanism diagnostics, not replacements for approved Exp1 scores.

Required controls: first-update known answer, exact optimizer provenance, monolithic/segmented equivalence on the intended GPU/precision, untouched original fit reference, fixed-pool intermediate losses, stable holdout and zero-LR sampling-only observation control. Optimizer-sensitive overshoot predicts that smaller rates reduce fixed-pool amplification. Pure minibatch noise predicts minibatch spikes without corresponding fixed-pool spikes. Finite-budget limitation predicts a shrinking trained/fresh gap with additional fitting; persistent held-out gaps under multiple task types motivate representational explanations.

## 4. Test whether initial function scale explains final error

Use stored predictions/targets first: decompose initial error into centered prediction variance, target variance, covariance and mean residual. Regress final error on these components within task/architecture/check, with training-seed holdout. That analysis needs no training if snapshots exist. Compare mean Q alone against centered components. A successful explanation predicts held-out final errors and counterexamples, including negative deficits with poor actors. If snapshots are absent, add only saved-task diagnostic forward passes before considering fitting.

A researcher-approved secondary control can compare an output-centered parameterization/calibration or decay treatment against an original matched task, but such a diagnostic must be separately labeled and cannot be presented as the historical protocol. Weight-decay changes and shared-offset choices require explicit approval. Falsify a mean-Q-only account if equal means yield widely different centered errors or if mean adjustment fails while variance/covariance predicts outcomes. Compute is bounded by selected forward passes; quote measured throughput, batch/pool size and architecture before estimating wall time.

## 5. Prospective prediction before a causal actor-continuation experiment

Freeze the current simple predictor, all transforms, windows and endpoints. Evaluate on independent parent seeds or previously inaccessible future trajectories; do not retune on those outcomes. Include baseline, Q-only, deficit-only and combined models. Primary endpoint: held-out next-return-change MSE and calibrated downside-event prediction separately. Use the same evaluation episode count across compared windows, and report event prevalence/precision-recall rather than only accuracy. Null prediction: deficit adds no information beyond Q/progress; this is already plausible in the present data. This stage can be CPU-only on newly recovered evidence.

Only after a reliable phenotype is isolated, propose an actor continuation: affected large pen or key task plus a nonaffected humanoid control; eight parent seeds each; randomized matched identity versus a researcher-chosen critic-only manipulation; preserve actor/replay/normalizer/RNG/optimizer state as specified. The manipulation must first change the intended critic phenotype while calibrating any immediate Q/action-gradient changes. Record10evaluation episodes at regular matched intervals and per-episode outputs, calibrated Q errors, policy KL/churn/gradients and probe components.

Nominal continuation budget:2tasks×8parents×2arms×0.1million raw steps=3.2million raw steps. At an explicit assumed100raw steps/s, interaction time alone is8.89device-hours; at500steps/s it is1.78hours, excluding diagnostics/compilation. Existing source performance cannot justify either throughput assumption without measurement. Parent reconstruction/qualification and task-specific intervention choices may dominate. No new parent grid is proposed as the first action. A causal claim needs an intervention-induced critic change followed by a matched actor effect and controls excluding direct action-function disruption. Null or opposite actor effects are valid falsifications, not failed experiments to be hidden.
